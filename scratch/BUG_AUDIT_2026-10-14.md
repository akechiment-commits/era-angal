# 追加バグ調査（2026-10-14）

現行作業ツリーを対象に学校生活・年月遷移・学校行事・パートナー導線とメニュー入力を調査。前回修正した学力購入と主人公能力選択の問題は除外。本調査ではゲームソース・セーブを変更していない。以下は静的確認とソースから抽出した数値・対応表の検証結果。Emuera上での操作再現は未実施。

## 1. [P1] 休憩所で不正入力するとキャラ配列の範囲外を参照

- 場所：ERB/SHOP_ショップ.ERB:1303（@KYUUKEIJO）。導線はショップ[107]休憩所。
- 入力のキャンセルと全員指示を処理した直後、CFLAG:RESULT:21を参照する。範囲チェックは1315行目で、その前に参照している。
- 再現条件：休憩所で9999を入力。主人公・助手・パートナーの番号と一致しないので、CFLAG:9999:21を読む。通常のキャラ登録数を超えるため停止する経路となる。負数-2も同様。
- 修正案：特殊番号を処理した後、RESULT < 0 || RESULT >= CHARANUMを判定し、キャラ配列に触る前に戻す。

## 2. [P1] 小物入れで不正入力するとLOCAL配列の範囲外を参照

- 場所：ERB/ACCESSORY_アクセサリーシステム.ERB:162（@ACCESSORY_SHOW）。ショップ[160]からアクセサリを持っている時に利用できる。
- 終了と自動装備切替番号以外をELSEIF LOCAL:RESULTで検査するが、入力範囲を先に確認していない。
- CSV/VariableSize.CSVでLOCALは1000要素。-2ならLOCAL:-2、1001ならLOCAL:1001にアクセスする。
- 再現条件：アクセサリを1個以上持った状態で小物入れを開き、-2または1001を入力。
- 修正案：特殊番号を処理した後、アクセサリ一覧の範囲0〜99を確認してからLOCALを読む。

## 3. [P2] 学校行事の一覧にNo.72あんずが表示されない

- 場所：ERB/SCHOOL_EVENT_体育祭・文化祭.ERB:753（@SHOW_EVENT_PARTNER_LIST）。
- 一覧ループはFOR LOCAL, 1, 72。EmueraのFORは終端を含まないため、実際には1〜71のみを走査する。
- 選択処理は716行目でA > 72を拒否する形に修正済みなので、一覧の終端だけ取り残されている。
- 再現条件：あんずを解禁し、現在のパートナーを別キャラにした状態で学校行事の3ページ目を開く。No.72のボタン171が表示されない。171を手入力する、またはあんずを現パートナーにして[8]を選ぶ回避は可能。
- 修正案：FOR LOCAL, 1, 73へ変更。

## 4. [P2] 年末から年始へ進むと表示年・記念日の日付が戻る

- 場所：ERB/DAYS_日付・天気・曜日.ERB:32,48,510,527。
- 月は4月スタートで1〜3月へ回り込むが、年はDAY / 120で増やすため、年の加算が1月ではなく4月に起きる。
- 数値再現（開始年2015）：DAY89=2015年12月28日 → DAY90=2015年1月1日。DAY119=2015年3月28日 → DAY120=2016年4月1日。
- GET_CURRENT_DATE_INTとCONVERT_DAY_INT_TO_DATE_INTも同じ年式を使う。画面表示だけでなく、初キス・恋人・相愛などの記念日記録も1〜3月が前年になって保存される。
- 修正案：暦年は(DAY + 30) / 120 + 開始年で算出。旧記念日変換も同じ式へ統一。学年・年度の判定は暦年と分けて扱う。DAY:3は年間行事等の実施済みキーにも使うので、その利用箇所まで確認して直す必要がある。

- LOCATION_SOLO_EVENTの報酬はMASTER指定がなくTARGETを更新する問題があるが、全9教室・27部室・7委員会室には1人以上が固定登録されており、現行通常メニューからソロ分岐へ到達しないため、上記5件には含めていない。
