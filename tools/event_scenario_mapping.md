# イベントボード用シナリオ番号仕分け

## この表の見方

- 対象は `ERB/EVENT_BOARD_DATA_イベントデータ.ERB` に登録されている52イベント。
- 番号は `tools/scenarios/<番号>.txt` の番号であり、カードIDではない。
- 範囲は、開催順、イベントカードの登場人物、本文中の話題、前後の物語の切り替わりを照合して決定した。
- 「高」は前後で舞台・話題・主要人物が明確に切り替わるもの。「中」は古いイベントなど、構成が特殊で境界に再確認の余地があるもの。

## カードIDと取り違えやすい例

`極楽＊ゆらぐ心と温泉街` のピックアップカードIDには `1482` が含まれるが、
シナリオ `1482.txt` はハワイを舞台にした `トロピカル＊水着と恋の南国旅行！` の一話である。
温泉街イベントの本文は `2459.txt` から `2476.txt` にまとまっている。

したがって、概要作成ではイベントデータ側のカード番号ではなく、この表のシナリオ範囲を読む必要がある。
