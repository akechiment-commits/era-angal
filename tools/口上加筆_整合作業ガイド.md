### C. 台詞は「生きた人間の言葉」（ゲーム用語・メタ厳禁）
- **「ウフフ」はシステムのモード名＝ゲーム用語。台詞「」内で言わせるな**（「ウフフでもないのに」等は厳禁）。
  → 人間の言葉に（「こんな明るいうちから」「いきなり、こんなとこで」「ちゃんとした場所でもないのに」「こんな急に」等）。
  ※「うふふ」(ひらがな＝笑い声)はOK。「ウフフ」(カタカナ＝モード名)が台詞内にあったらNG。
- §7「実演で書く」厳守＝説明・実況・ナレーション化を排除（「服越しに繋がる」「着衣で背徳的」等の状況説明台詞はNG＝地の文の仕事）。台詞はキャラの声・感覚・反応で。
- **★三点リーダ「……」は控えめに（2026-06-11 明智さん指摘）**：1台詞に「……」を盛りすぎない。喘ぎ・余韻の表現を「……」連発に頼らず、語尾・擬音・短文のテンポで作る。目安＝通常コマンドは0〜1個／強い場面で2個／崩壊・絶頂の最高潮でのみ3個以上。読点「、」や言い差し「っ。」で間を作り、機械的な「……」反復を避ける。既済キャラも今後の見直し時に逓減。
- **★女子相手COMは相手の女性に注目／コマンド解説をしない（2026-06-11 明智さん指摘）**：相手＝女子(%LOCALS%)のCOMでは、台詞は**相手の女性の反応・かわいさ＋キャラの愛撫/感覚**に集中。「転校生が見てる／命令だから／見ててね」等の**メタ参照を入れない**（主人公が実際の相手の行為＝オナニー見せ・デート等は例外）。「攻める番／挿れる側／ペニバン挿れられて／攻守逆転／女の子同士なのに」等の**コマンド内容を解説する台詞も避ける**（§6-C／§7）。
- **★「ん」始まり台詞の連発禁止（2026-06-14 明智さん指摘）**：台詞冒頭を「ん、」「んっ」「ん……」で始めるのは**岩戸サン(CHAR_57＝「ん」が口癖)のみの特権**。それ以外のキャラで冒頭「ん」が多すぎると不自然（AI生成は喘ぎも会話も「ん、」で始めがち）。**冒頭「ん」率の目安＝全口上の15%以下**（岩戸のみ20%超可）。各キャラ固有の口癖開始語（例：まい=あはは/ほら、かいり=えへへ/わぁ、かな=ふんっ/あら、ゆう=ふふ/ふぅん/ふあぁ、るな=うひゃひゃ/ほれ、みけ=にゃ系）で開始を散らす。喘ぎ冒頭も「あっ/はぁ/ふぁ/あぁ/ひゃ」等に分散。
  - 検出/一括是正ツール：`/tmp/n_sweep.py` 方式＝**各キャラ自身の既存非ん開始語を自動抽出してプール化→冒頭んクラスタを置換（句読点保持・視点/メタ不変）**。2026-06-14に全コーパス是正済（岩戸以外34キャラを≤15%へ。岩戸57=23%で口癖どおり突出）。**新規執筆・今後の各キャラ作業でも冒頭んの分散を必ず意識**する。

## 2. キャラ1体の標準手順（5ステップ）

### Step 1：本物のキャラ像を確定（着手ゲート）
1. `tools/character_data.csv` の正史プロフィールを読む（部活・性格・人間関係）。
2. `tools/output/{名前}_分析.txt` の **一人称・語尾・呼称・感情分布**を見る。
3. `tools/output/{名前}_転校生.txt` で**主人公呼称**を確定（例：先輩／お兄ちゃん先輩／ジョンくん／転校生さん）。
4. **★一次資料の汚染チェック★**：`grep -nE "入れ替|憑|別人|中身が" tools/output/{名前}.txt`。
   ヒットしたら本文を読み、**精神入れ替わり等のアーク**なら該当シナリオIDを**除外**して
   一人称/語尾を再集計する（§5参照）。誤検出（比喩・シフト交代等）なら無視。
5. **「言いそうにない言い回し」を先に言語化**しておく（§4）。

### Step 2：既存ERBの声スキャン
```python
serif=[l for l in t.split('\n') if 'PRINTFORM' in l and '「' in l]
```

## 4. 声・一人称・OOC語彙

- **一人称はキャラ固有形で固定**：私(かなえ＝ツン自信家)／わたし・ひらがな(ゆき・ちよ)／あっし(むつみ)など。
  「あたし」等の非キャラ形が混入していたら修正。
- **崩壊（絶頂）時の人称揺らぎは“原作一人称ベース”で**。例：ちよ＝わたし/うち/じぶん（あたしは使わない）。
  ※人称揺らぎは演出の一手段にすぎず必須ではない（手順書§6）。
- **★キャラ別 OOC（言いそうにない言い回し）★** … 着手時に言語化し、完成時に grep で0確認：
  - **榊むつみ(42)**：「ちまう」「やがる」は**絶対に言わない**。ちまう系は必ずます形「ちまいやす／ちまいやした」
    （ちまいそうはOK）。やがる系（やがる/やがります/やがって）は**全廃して言い換え**
    （責めてくる／超えてきやす／じみてきやす 等）。
  - **内気・おっとり系（ゆき・ちよ）**：むつみ的な荒い語（あっし/ですぜ/モチのロン）や強いツン・がさつ表現はNG。
  - 一般に、そのキャラの分析・原作にない口調は持ち込まない。

## 5. 一次資料の汚染（入れ替わり・憑依）

- 対応：該当シナリオを**除外して**一人称・語尾・呼称を再集計（除外後に異物が0になることで検算）。
  原作verbatim も**クリーン分から**のみ採る。
- ※この入れ替わりは かなえ⇔むつみ の1回限り（手順書本体への恒久ルール追記は不要）。
  他キャラで汚染が疑われたら Step1-4 の grep で個別に確認する。

## 8. 技術（cp932 / CRLF / 編集スクリプトひな型）

- **ERB/CSV は cp932 + CRLF**。`tools/*.txt/*.md` は **UTF-8**（混同しない。診断ファイルは UTF-8）。
- **行ごと再構築すると末尾 `\r` が落ちて LF 混入**する → 保存前に必ず CRLF 正規化。
- encode は変数に確定してから `open('wb')`（1行 write は全損事故）。各行 `encode('cp932')` で事前検査。
- **EM DASH `—`(U+2014) は cp932 不可** → ERB既存の全角ダッシュ `―`(U+2015) へ正規化（波ダッシュ正規化と同種）。
- 半角 `~`(U+007E) 厳禁。波線は `～`(U+FF5E)／`〜`(U+301C)（cp932では同一バイト）。

```python
import re
COM='ERB/CHAR/CHAR_NN_名前_COM.ERB'
t=open(COM,'rb').read().decode('cp932')

# --- B/C/声：exact 行置換（必ず repr で取得した現物をキーに） ---
repl={ '旧セリフ全文':'新セリフ全文', ... }
for o,n in repl.items():
    assert t.count(f'「{o}」')==1, f'NG:{o[:24]}'   # 一意確認
    t=t.replace(f'「{o}」', f'「{n}」')

# --- A：空スロを構造位置で順に埋める ---
lines=t.split('\n')
def fill(com, texts):
    on=False; idx=[]
    for i,l in enumerate(lines):
        m=re.search(r'SELECTCOM\s*==\s*(\d+)',l)
        if m:
            if on: break
            if int(m.group(1))==com: on=True; continue
        if on and 'PRINTFORMW 「」' in l: idx.append(i)
    assert len(idx)==len(texts), f'COM{com}:{len(idx)}!={len(texts)}'
    for i,x in zip(idx,texts):
        ind=lines[i][:len(lines[i])-len(lines[i].lstrip())]
        lines[i]=f'{ind}PRINTFORMW 「{x}」'
# fill(323,[...12個...]) など
t='\n'.join(lines)

# --- 保存：CRLF正規化＋cp932事前検査 ---
norm='\r\n'.join(l.rstrip('\r') for l in t.split('\n'))
for l in norm.split('\r\n'): l.encode('cp932')   # 不可文字を早期検出
assert '~' not in norm
open(COM,'wb').write(norm.encode('cp932'))
```
