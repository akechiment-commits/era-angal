- 会話(COM301)・スキンシップ(COM303)・まったり(COM304)に、**clean原作の一字一句コピー**を各1〜2本。
- 一対一で成立／場面に合う／そのキャラ人格のものを選ぶ。自作スロを原作で上書き（テーマ被りは一本化）。
- 季節限定（例：桜）など**いつでも出る会話スロに不適なもの**は採らない（無理に入れない・0本可だがまず探す）。
- ★**文脈成立性チェック（最重要）**★：原作セリフは多くが「特定場面への反応の断片」。仕込む前に
  **「それ単体を会話スロにポンと置いて、指示語・前提が宙に浮かないか」**を必ず判定する。
  - NG例：「誇ってもいいと、思うよ」（何を誇る？）／「まったくもう、変に意地っぱりなんだから」（誰が？）／
    「ううん。嬉しいよお」（何への“ううん”？）／「それがね、すっごい幸せ」（“それ”が無い）。
    → こういう断片は**採らない**。無理に入れるくらいなら自作の文脈成立セリフを残す。

    その場の行為への反応（抱擁中「抱きしめちゃ駄目ですよお兄ちゃん」、くすぐり中「背中はやめるだよぉ」）／
    身近な人物の描写（「堀田先輩、強すぎ！冷静だし〜」）。指示語が**そのスロット内**で解決するものはOK。
  - 数より質。**破綻1本より、確実に成立する2本**。0本回避のために宙に浮く断片を入れるのは本末転倒。

## 8. 技術（cp932 / CRLF / 編集スクリプトひな型）

- **ERB/CSV は cp932 + CRLF**。`tools/*.txt/*.md` は **UTF-8**（混同しない。診断ファイルは UTF-8）。
- **行ごと再構築すると末尾 `\r` が落ちて LF 混入**する → 保存前に必ず CRLF 正規化。
- encode は変数に確定してから `open('wb')`（1行 write は全損事故）。各行 `encode('cp932')` で事前検査。
- **EM DASH `—`(U+2014) は cp932 不可** → ERB既存の全角ダッシュ `―`(U+2015) へ正規化（波ダッシュ正規化と同種）。
- 半角 `~`(U+007E) 厳禁。波線は `～`(U+FF5E)／`〜`(U+301C)（cp932では同一バイト）。

```python
import re
COM='ERB/CHAR/CHAR_NN_名前_COM.ERB'
t=open(COM,'rb').read().decode('cp932')

# --- B/C/声：exact 行置換（必ず repr で取得した現物をキーに） ---
repl={ '旧セリフ全文':'新セリフ全文', ... }
for o,n in repl.items():
    assert t.count(f'「{o}」')==1, f'NG:{o[:24]}'   # 一意確認
    t=t.replace(f'「{o}」', f'「{n}」')

# --- A：空スロを構造位置で順に埋める ---
lines=t.split('\n')
def fill(com, texts):
    on=False; idx=[]
    for i,l in enumerate(lines):
        m=re.search(r'SELECTCOM\s*==\s*(\d+)',l)
        if m:
            if on: break
            if int(m.group(1))==com: on=True; continue
        if on and 'PRINTFORMW 「」' in l: idx.append(i)
    assert len(idx)==len(texts), f'COM{com}:{len(idx)}!={len(texts)}'
    for i,x in zip(idx,texts):
        ind=lines[i][:len(lines[i])-len(lines[i].lstrip())]
        lines[i]=f'{ind}PRINTFORMW 「{x}」'
# fill(323,[...12個...]) など
t='\n'.join(lines)

# --- 保存：CRLF正規化＋cp932事前検査 ---
norm='\r\n'.join(l.rstrip('\r') for l in t.split('\n'))
for l in norm.split('\r\n'): l.encode('cp932')   # 不可文字を早期検出
assert '~' not in norm
open(COM,'wb').write(norm.encode('cp932'))
```
