## 2. キャラ1体の標準手順（5ステップ）

### Step 1：本物のキャラ像を確定（着手ゲート）
1. `tools/character_data.csv` の正史プロフィールを読む（部活・性格・人間関係）。
2. `tools/output/{名前}_分析.txt` の **一人称・語尾・呼称・感情分布**を見る。
3. `tools/output/{名前}_転校生.txt` で**主人公呼称**を確定（例：先輩／お兄ちゃん先輩／ジョンくん／転校生さん）。
4. **★一次資料の汚染チェック★**：`grep -nE "入れ替|憑|別人|中身が" tools/output/{名前}.txt`。
   ヒットしたら本文を読み、**精神入れ替わり等のアーク**なら該当シナリオIDを**除外**して
   一人称/語尾を再集計する（§5参照）。誤検出（比喩・シフト交代等）なら無視。
5. **「言いそうにない言い回し」を先に言語化**しておく（§4）。

### Step 2：既存ERBの声スキャン
```python
serif=[l for l in t.split('\n') if 'PRINTFORM' in l and '「' in l]
# 一人称カウント・OOC語彙カウント（あっし/ですぜ/やがる/ちまう 等が混じってないか）
```
- 一人称がキャラ固有形（私／わたし／あっし…）で安定しているか。**あたし等の混入は声修正対象**。
- むつみ的な荒い語が内気キャラに混じってないか（汚染や流用ミス）。

### Step 3：AITE_YOBI 登録確認
`ERB/AITE_YOBI_相手呼称.ERB` で自分のキャラ番号が
(1)既定／(2)個別に登録されているか確認。casual キャラは(1)未登録＝CASEELSE「呼び名」で適切なこともある。

### Step 4：対象現物を**正確に取得 → 編集スクリプト**
- **必ず repr で正確な現物文字列を取る**（手元メモやスライス表示は末尾「っ」やダッシュがズレる）。
- B/C/声は exact 行置換（`t.count(old)==1` で一意確認）、A は構造位置で `PRINTFORMW 「」` を順に埋める。
- §6 の編集スクリプトひな型を使う。

### Step 5：検算 → 記録 → commit
- §7 の検算チェックリストを全項目通す。
- `tools/CHAR_NN_{名前}_整合記録.txt`（UTF-8）に像・実施・検算を残す。
- 作業ブランチへ随時 commit / push（master 反映は区切りで）。

## 4. 声・一人称・OOC語彙

- **一人称はキャラ固有形で固定**：私(かなえ＝ツン自信家)／わたし・ひらがな(ゆき・ちよ)／あっし(むつみ)など。
  「あたし」等の非キャラ形が混入していたら修正。
- **崩壊（絶頂）時の人称揺らぎは“原作一人称ベース”で**。例：ちよ＝わたし/うち/じぶん（あたしは使わない）。
  ※人称揺らぎは演出の一手段にすぎず必須ではない（手順書§6）。
- **★キャラ別 OOC（言いそうにない言い回し）★** … 着手時に言語化し、完成時に grep で0確認：
  - **榊むつみ(42)**：「ちまう」「やがる」は**絶対に言わない**。ちまう系は必ずます形「ちまいやす／ちまいやした」
    （ちまいそうはOK）。やがる系（やがる/やがります/やがって）は**全廃して言い換え**
    （責めてくる／超えてきやす／じみてきやす 等）。
  - **内気・おっとり系（ゆき・ちよ）**：むつみ的な荒い語（あっし/ですぜ/モチのロン）や強いツン・がさつ表現はNG。
  - 一般に、そのキャラの分析・原作にない口調は持ち込まない。

### D 原作 verbatim（全キャラ必須・手順書§4-C/§10-C）
- 会話(COM301)・スキンシップ(COM303)・まったり(COM304)に、**clean原作の一字一句コピー**を各1〜2本。
- 一対一で成立／場面に合う／そのキャラ人格のものを選ぶ。自作スロを原作で上書き（テーマ被りは一本化）。
- 季節限定（例：桜）など**いつでも出る会話スロに不適なもの**は採らない（無理に入れない・0本可だがまず探す）。
- ★**文脈成立性チェック（最重要）**★：原作セリフは多くが「特定場面への反応の断片」。仕込む前に
  **「それ単体を会話スロにポンと置いて、指示語・前提が宙に浮かないか」**を必ず判定する。
  - NG例：「誇ってもいいと、思うよ」（何を誇る？）／「まったくもう、変に意地っぱりなんだから」（誰が？）／
    「ううん。嬉しいよお」（何への“ううん”？）／「それがね、すっごい幸せ」（“それ”が無い）。
    → こういう断片は**採らない**。無理に入れるくらいなら自作の文脈成立セリフを残す。
  - OK例：自己紹介（「merry-melody所属の羽森つばさであります！」）／自己完結の小話（「つばさしゃん生活能力ねぇがら家事はぜんぶおらが」）／
    その場の行為への反応（抱擁中「抱きしめちゃ駄目ですよお兄ちゃん」、くすぐり中「背中はやめるだよぉ」）／
    身近な人物の描写（「堀田先輩、強すぎ！冷静だし〜」）。指示語が**そのスロット内**で解決するものはOK。
  - 数より質。**破綻1本より、確実に成立する2本**。0本回避のために宙に浮く断片を入れるのは本末転倒。
- 抽出スニペット（既に仕込まれているか／候補探し）：
```python
quotes=[q for q in re.findall(r'「([^」]+)」', open(src,encoding='utf-8').read()) if len(q)>=12]
# 口上行に原作12字連続が含まれるか（双方向部分一致）で機械判定
```

### E-2 地の文の加筆手順（独自枠・CHAR_01から順に / 2026-06-05〜）

地の文の空枠は§Eの「地の文の枠」で `@KOJO_MESSAGE_COM_<NO>` 内の各コマンド口上の隣に用意済み。
**CHAR_01 から番号順**に、未執筆枠を埋めていく。1コマンド＝1枠（場面）。

1. **対象枠を特定**：`CHAR_<NN>_*_COM.ERB` を cp932 で読み、`;◆地の文枠（場面: …）※未執筆` を探す。
   直下の `;PRINTFORMW`（コメント）が空枠。場面名は同行に表示済み（CSTR:80-89 由来）。
2. **題材確認**：その場面（例 280=楽器庫の秘密）に合う情景を、口上(「」)の内容と矛盾しないよう確認。
   原作一次資料（tools/scenarios・output・prompt_*）で人物像を外さない。
3. **本文を書く（実演型・§7厳守）**：
   - `;◆…` ラベル行は**残す**。その下の `;PRINTFORMW` の `;` を外し、`PRINTFORMW <地の文>` にする（複数行可）。
   - **地の文に「」は使わない**（「」は口上の領分）。描写＝行為・情景・身体反応・擬音。説明/実況/メタは書かない（§7）。

## 8. 技術（cp932 / CRLF / 編集スクリプトひな型）

- **ERB/CSV は cp932 + CRLF**。`tools/*.txt/*.md` は **UTF-8**（混同しない。診断ファイルは UTF-8）。
- **行ごと再構築すると末尾 `\r` が落ちて LF 混入**する → 保存前に必ず CRLF 正規化。
- encode は変数に確定してから `open('wb')`（1行 write は全損事故）。各行 `encode('cp932')` で事前検査。
- **EM DASH `—`(U+2014) は cp932 不可** → ERB既存の全角ダッシュ `―`(U+2015) へ正規化（波ダッシュ正規化と同種）。
- 半角 `~`(U+007E) 厳禁。波線は `～`(U+FF5E)／`〜`(U+301C)（cp932では同一バイト）。

```python
import re
COM='ERB/CHAR/CHAR_NN_名前_COM.ERB'
t=open(COM,'rb').read().decode('cp932')

# --- B/C/声：exact 行置換（必ず repr で取得した現物をキーに） ---
repl={ '旧セリフ全文':'新セリフ全文', ... }
for o,n in repl.items():
    assert t.count(f'「{o}」')==1, f'NG:{o[:24]}'   # 一意確認
    t=t.replace(f'「{o}」', f'「{n}」')

# --- A：空スロを構造位置で順に埋める ---
lines=t.split('\n')
def fill(com, texts):
    on=False; idx=[]
    for i,l in enumerate(lines):
        m=re.search(r'SELECTCOM\s*==\s*(\d+)',l)
        if m:
            if on: break
            if int(m.group(1))==com: on=True; continue
        if on and 'PRINTFORMW 「」' in l: idx.append(i)
    assert len(idx)==len(texts), f'COM{com}:{len(idx)}!={len(texts)}'
    for i,x in zip(idx,texts):
        ind=lines[i][:len(lines[i])-len(lines[i].lstrip())]
        lines[i]=f'{ind}PRINTFORMW 「{x}」'
# fill(323,[...12個...]) など
t='\n'.join(lines)

# --- 保存：CRLF正規化＋cp932事前検査 ---
norm='\r\n'.join(l.rstrip('\r') for l in t.split('\n'))
for l in norm.split('\r\n'): l.encode('cp932')   # 不可文字を早期検出
assert '~' not in norm
open(COM,'wb').write(norm.encode('cp932'))
```
