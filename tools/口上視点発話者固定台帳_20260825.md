# 口上視点・発話者固定台帳

最終更新：2026-08-25  
用途：CHAR口上を編集する前に、コマンド番号ごとの「行為者」「受け手」「台詞の発話者」を固定する。  
上位資料：`tools/現在作業メモ_視点整合再監査_20260825.md`  

この台帳は、コマンド名の字面、直前に見た別COM、過去の要約、既存台詞の雰囲気より優先する。台帳と実装説明が食い違った場合は編集を停止し、どちらを採用するか確定するまで本文を書かない。

## 1. 役割の定義

| 記号 | 意味 |
|---|---|
| PLAYER | 転校生くん。ゲーム上のプレイヤー。 |
| TARGET | 現在編集しているキャラクター。今回なら日滝ましろ。 |
| ASSI | 女性助手・他女子。存在するCOMだけで使う。 |
| 行為者 | 触る・撫でる・挿入する・飲むなど、実際に動作を行う側。 |
| 受け手 | 動作を受け、身体・感情の反応を出す側。 |
| 発話者 | その台詞を実際に言っている人物。行為者・受け手と別に必ず確定する。 |

「行為者＝発話者」「受け手＝発話者」と決め打ちしない。特にPLAYERが行為者・発話者でも、主人公の台詞を表示せずTARGETの反応だけを書くCOM311のような枠がある。

現在の対象CHARは、その都度作業メモの作業ロックで固定する。以下の表は全CHAR共通の方向規則であり、直前のキャラ名を対象CHARとして扱わない。

## 2. 絶対固定の逆向きペア

| COM | 表示名 | 行為者 | 受け手 | 基本の発話者 | 反対向きにしてはいけない例 |
|---:|---|---|---|---|---|
| 37 | 足扱き | TARGETが自分の足でPLAYERを扱く | PLAYER | TARGETまたは実装指定の発話者 | TARGETが「おまえの足で私のを」と言う形にしない |
| 67 | 足コキ | PLAYERの足がTARGETのふたなりを扱く | TARGET | TARGETの反応 | TARGETが「私の足でおまえのを」と言う形にしない |
| 306 | 髪梳き | PLAYERがTARGETの髪を手で梳く | TARGET | TARGETの反応 | TARGETがPLAYERの髪を梳く形にしない |
| 307 | 櫛で梳かす | PLAYERがTARGETの髪を櫛で梳く | TARGET | TARGETの反応 | TARGETが「頭を貸して」など、PLAYERを梳く形にしない |
| 312 | 頭を撫でる | PLAYERがTARGETの頭を撫でる | TARGET | COM311の甘い言葉を混ぜない。TARGETがPLAYERを撫でる側にも反転させない |
| 316 | 髪を梳く | TARGETがPLAYERの髪を梳く | PLAYER | TARGET | TARGET自身が梳かれる反応にしない |
| 318 | 頭を撫でてもらう | TARGETがPLAYERの頭を撫でる | PLAYER | TARGET | TARGET自身が撫でられる反応にしない |

### COM312とCOM318の発話規則

- COM312はPLAYERがTARGETを撫でる。COM312の台詞は頭を撫でられたTARGETの反応に限定し、COM311の甘い言葉を混ぜない。
- COM318はTARGETがPLAYERを撫でる。慰め・甘い言葉はTARGETがPLAYERへ言う。TARGET自身が撫でられる台詞を書かない。
- COM312を確認するときにCOM318へ移動しない。COM318を確認するときにCOM312へ移動しない。
- 312/318の両方を直す必要がある場合でも、必ず一方を完全確認してからもう一方へ進む。

### フェラの発話者チェック

- COM4はTARGETの受け反応を書く。TARGETが「私のを咥えるのか」と言うのは、PLAYERがTARGETのものを咥える意味なら可。TARGET自身が咥える動作を宣言してはいけない。
- COM31はTARGETが奉仕する側。TARGETの口・舌・奉仕の反応を書く。PLAYERを咥えられる側としてTARGETが実況する構造にしない。
- COM66はTARGET一人がPLAYERとASSIの二本を舐める。二本の所有者と、舐める側を混ぜない。
- COM68はTARGETとASSIがPLAYER一本を舐める。TARGETとASSIの二人が奉仕する側であり、TARGETが受ける双方向フェラにはしない。
- COM30はTARGETがPLAYERを手で扱く側。TARGETの奉仕反応を書く。
- COM191はPLAYERがTARGETのふたなりを手で扱く側。TARGETは手淫される反応を書く。
- COM30とCOM191は手の主語・ペニスの所有者・反応者を必ず分け、片方の台詞をもう片方へ流用しない。
- 「フェラ」「咥える」だけを検索して判断しない。口を使う人物、ペニスの所有者、台詞の発話者を三列で照合する。

## 5. 編集前の強制ロック

編集を開始する前に、作業メモへ次の6項目を埋める。1項目でも空欄・推測・資料間の不一致があれば、本文を編集しない。

```text
対象CHAR：
対象COM：
根拠資料の行／COMF：
行為者：
受け手：
発話者：
このCOMで絶対に書かない向き：
```

その後、対象COMの全分岐（初回、失敗、恋人、親密、通常、A=0/A=1/ELSE）を一つのブロックとして抽出する。隣のCOMは参照しても編集対象にしない。

## 6. 編集後の強制確認

1. 変更したファイルとCOM番号が対象ロックと一致するか確認する。
2. 対象ブロックを先頭から末尾まで再読し、行為者・受け手・発話者を各行に割り当てる。
3. 逆向きペアの禁止例が1つもないか検索する。
4. 同じCOM内の全分岐を確認する。A=0だけ見て完了にしない。
5. CP932、CRLF、IF/ENDIF、RAND:3、完全一致重複を監査する。
6. 監査が通っても、台詞の主語・目的語・発話者がロックと一致しなければ未完了とする。

## 7. 作業停止条件

- COM番号を取り違えた可能性がある。
- 行為者と発話者が別で、台詞の出力形式が確定していない。
- COMF、現在作業メモ、直上注釈が一致しない。
- 直前の別CHAR・別COMの台詞を参考にしないと書けない。
- 「たぶん」「おそらく」「この場合も同じ」が必要になる。

停止条件に入った場合は、修正案を作らず、対象COMと不一致点だけを報告する。
