# イベント詳細台本（試作）

このファイルは、既存の5段階イベント物語表示を複数行の掛け合いへ拡張するための台本です。

- 未登録のイベントは、従来の `event_scenario_summaries.md`／`event_scenario_milestones.md`／`event_scenario_recollections.md` を表示します。
- 各イベントは「概要」「導入」「5000PT」「10000PT」「15000PT」「完走」の6段階を持ちます。
- 「概要」はイベント開始時に導入セリフより先に表示する地の文です。
- 「概要」以外は、1行につき `話者「台詞」` を1つ置きます。
- 現在登録している56イベント分を、元シナリオの内容に沿って整理しています。
