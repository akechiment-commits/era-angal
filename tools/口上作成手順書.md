## 1. 作業対象ファイルの場所

### キャラごとに存在するファイル（3種）

```
ERB/CHAR/CHAR_NN_名前.ERB        ← ベースERB（行事・挨拶・エンディング等、約100スロ）
ERB/CHAR/CHAR_NN_名前_COM.ERB    ← COMERBメイン（936スロ、主作業）
CSV/CharaNN_名前.csv              ← 素質定義（キャラのパラメータ）
```

`NN` はキャラ番号（01〜71）。

### 参照資料ファイル（キャラ別）

```
tools/prompt_{ひらがな名}.txt     ← キャラプロファイル＋原作セリフ一覧（★最重要）
```

例: さあやなら `tools/prompt_さあや.txt`

prompt ファイルの中身:
- ゲーム内プロフィール（身長・誕生日・部活・紹介文など）
- 話し方・性格（一人称・語尾・口癖・頻出ワード）
- 人間関係（誰と何話共演しているか）
- 原作セリフ全文

### シナリオ参照（必要に応じて）

```
tools/scenarios/{番号}.txt        ← ゲーム内シナリオ原文
tools/story_ids.txt               ← シナリオIDとタイトル一覧
```

## 2. ステップ0: 設定.txt を作る（着手前に明智さんの確認を取る）

### やること

1. `tools/prompt_{名前}.txt` を読んで原作セリフ・性格を把握する
2. `tools/talent_list.txt` を参照しながら素質を選ぶ

3. 紹介文（一人称・口調・性格核・人間関係・主人公呼称）をまとめる
4. 明智さんに見せて確認をもらう

### 設定.txt の保存先

```
/mnt/user-data/outputs/CHAR_NN_{名前}_設定.txt
```

```

```

書き込み先セクションはどれも `@KOJO_MESSAGE_COM_NN` の中。
内部は `IF SELECTCOM == NNN` で分岐。

### ステップ2: 純愛コミュ（200スロ）

```
COM300〜325（196スロ）＋ @HOURAI_KOJO_NN（4スロ）
```

**蓬莱の薬（@HOURAI_KOJO）の注意**:
- COM_ERBファイル内に `@HOURAI_KOJO_NN` が **2箇所**ある
- 1箇所目: COM310調合直後の4枠 ← **これが本物**
- 2箇所目: ファイル後半の大きなセクション
- 書き込み先: **1箇所目（早い方）** を使う

蓬莱4枠の構造（TFLAG:91で分岐）:
```
CASE 0: プレイヤーが先に飲むのを目撃
CASE 1: 自らの意志で飲む
CASE 2: 無理やり飲まされる
CASE 3: 飲むのを拒否
```

## 7. ファイルの読み書き

### 必須: Python で cp932 + CRLF

```python
# 読み込み
with open('ERB/CHAR/CHAR_NN_名前_COM.ERB', 'rb') as f:
    content = f.read().decode('cp932')

# 書き込み
with open('ERB/CHAR/CHAR_NN_名前_COM.ERB', 'wb') as f:
    f.write(content.encode('cp932'))
```

- **Edit ツール使用禁止**（UTF-8で上書きされて文字化けする）
- 波線は `〜`（U+301C）を使う。`~`（U+FF5E）は NG

## 8. ステップ完了時のバッチチェック

`引き継ぎ書_v21.txt` の「ステップ完了時のバッチチェックスクリプト」セクションに
Pythonコードあり。毎ステップ完了後に実行すること。

チェック項目:
- 装飾的呼称（`、{呼称}、`）
- 中途切れ語尾（`ちまうっ` / `やがるっ`）
- ワンパターン冒頭（1パターンが20%超でNG）
- 読点率（原作比 +0.5〜1.0個以内）
- 導入喘ぎ型率（通常15%以下・絶頂30%以下）
- 複絶頂・五重絶頂構造解説NG語句
- 空セリフ（`PRINTFORMW 「」`）
