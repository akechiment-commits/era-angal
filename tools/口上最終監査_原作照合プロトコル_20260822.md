## 1. 資料の優先順位

1. `tools/output/名前.txt`：原作セリフ全文。キャラクターの声を判断する一次資料。
2. `tools/output/名前_転校生.txt`：転校生との距離感・呼称・恋愛時の変化。
3. `tools/output/名前_関係性分析.txt`、設定書、v3prompt：補助資料。原作本文と矛盾したら原作本文を優先する。
4. `ERB/CHAR/CHAR_NN_名前_COM.ERB`：現在の口上。良い実例と修正対象を分けて使う。
5. `tools/口上作成手順書.md`、`tools/口上作業手引書_現行版_20260810.md`、本資料：実装・監査規則。

要約文やキャララベルだけから口調を推測しない。原作にない語尾・一人称・渾名・比喩を「それらしい」という理由だけで発明しない。

## 2. キャラ資料の作り方

キャラごとに `tools/キャラ資料/CHAR_NN_名前_原作照合.md` を作る。短い性格メモではなく、原作の根拠と解釈を分離した照合資料にする。

```md
# CHAR_NN 名前

## 原作の事実
- 一人称：
- 二人称・主人公の呼び方：
- 立場・人間関係：
- 原作で確認できる性格・感情：

## 原作実例
### 平常時
- [原作ファイル:行] 「実際のセリフ」
### 照れ・戸惑い

## 文章上の特徴
- 一人称・呼称：
- 語尾・助詞：原作の実例と頻度を併記

## 解釈（原作実例から導いたもの）

- 恋人未満：
```

原作本文を資料へ丸ごと複製しない。各項目に代表例を複数置き、必ずファイル名と行番号を残す。原作実例とこちらの解釈を同じ箇条書きに混ぜない。

## 3. 全キャラ共通の参加者・視点規約

セリフを書く前に、対象コマンドのCOMF定義とブロック直上の`;▼【視点】`／`;※`注釈を読む。コマンド名の「する／される」だけで主体を決めない。

最低限、次の表を確認する。

| コマンド | 口上上の主体 |
|---|---|
| COM43 | キャラが目隠しされる |
| COM44 | キャラが拘束される |
| COM45 | キャラが口枷される |
| COM130 | キャラがPLAYERを目隠しする |
| COM131 | キャラがPLAYERを拘束する |
| COM132 | キャラがPLAYERに口枷をする |
| COM302 | PLAYERがキャラへプレゼントを渡す。キャラは受け取る側 |

女性助手・他女子が関わるCOMでは、キャラ・PLAYER・助手／他女子の三者を先に書き出す。`%LOCALS%`は注釈と`CALL AITE_YOBI`の後で実際の相手を確定する。

## 4. 修正の順番

### 4.1 棚卸し

各キャラについて、追加10の有無、基礎158枠、RANDなし、RAND:3のA==1欠落、IF/ENDIF、空口上、視点疑い、完全一致・近似コピペを一覧化する。

### 4.2 機械的な修正

先に構造だけを直す。RANDの枠組み、欠落コマンド、注釈、IF/ENDIFなどが対象。既存のA=0本文を保存し、本文を一括置換しない。

### 4.3 視点修正

役割表とCOMF定義に照合し、キャラ・PLAYER・助手の誰が何をしているかを確認する。「される／させる」の語句検索だけで修正しない。

### 4.4 キャラ声の修正

原作照合資料、原作実例、既存口上の良例を同時に参照する。説明・実況を反応へ変える場合も、キャラ固有の語彙・テンポ・距離感を維持する。

### 4.5 コピペ修正

完全一致は機械検出するが、同じ状況で同じ反応が自然な場合は自動削除しない。残す1本を決め、他の分岐は感情のビート（戸惑い、照れ、欲、強がり、余韻など）ごと変える。語尾だけの置換は禁止。

## 5. RAND:3の設計

- A=0／A=1／ELSEの3本を用意する。
- 3本とも同じ導入・同じ感想・同じ着地にしない。
- 説明調は最大1本まで。残りはその瞬間に漏れる反応を中心にする。
- 恋人・通常の距離感を保つ。非恋人側へ恋人専用の甘さや受容を流用しない。
- RAND:3なのにA==1がない場合は、既存本文を確認してから分岐を補う。

## 6. 検証

キャラ単位で次を実行し、すべて通過してから完了扱いにする。

1. CP932往復・改行・IF/ENDIF
2. SELECTCOM、基礎枠、追加10、空口上
3. RANDなしとRAND:3のA==1欠落
4. コマンド役割別の視点監査
5. 完全一致・近似コピペ・導入語・三点リーダ頻度
6. 原作語尾・一人称・呼称の個別検索
7. 既存良例との声の照合
8. 追加10では新規60本を一行ずつ原作全文・転校生向け全文・照合資料へ戻し、語尾だけでなく、笑い・擬音・呼称・感情の崩れ方・説明癖を確認する。原作にない定型を複数本へ反復した場合は、機械監査が通っていても未完了とする。

監査で検出しただけの候補は「確定ミス」「要目視」「誤検出」に分類する。単純な語句ヒットをそのまま修正件数にしない。
