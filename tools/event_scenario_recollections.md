# イベント回想集

`event_scenario_summaries.md` の客観要約、`v3prompt` の人物定義、`output` のキャラクター別全セリフ集を照合し、各イベントの参加人物が後日その出来事を振り返る形へ書き直した。

- 話者は、そのイベントで大きく心境が動く人物を優先した。
- 52イベントすべてで異なる話者を割り当て、同じ人物を重複させていない。
- 一人称、語尾、口癖、呼称だけでなく、その人物が出来事をどう捉えるかも人物定義に合わせた。
- 出来事の流れだけでなく、話者が最後に得たものまで本人の視点で語らせている。
- ゲーム上では、各イベントの2万PT完走時に開催年ごとに一度だけ表示する台詞として使用する。
- 実装時の表示形式は見出しの「回想（名前）」ではなく、通常の `名前「……」` とする。
