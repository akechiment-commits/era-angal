# CHAR_45 円城寺れいか

## 原作の事実

- 一人称は基本「わたくし」。円城寺財閥令嬢、茶道部部長、前生徒会長。
- 策謀家のお嬢様として、お嬢様言葉・余裕・言葉による主導を使う。
- 同時に兄不在の寂しさと甘えたい本音があり、強い場面では「お兄さま」への甘えや幼児退行が滲む。
- 転校生は公的には「転校生くん」、甘え・恋慕では「転校生のお兄さま」「お兄さま」、からかいでは「坊や」。
- 「ふふ」「うふふ」「よろしくてよ」「かしら」「なさい」「♪☆」が核。荒い男言葉や粗い呻きは使わない。
