# 全CHAR 人格汚染・重複横断監査（2026-09-09）

## 監査範囲

- 対象：`ERB/CHAR/CHAR_*_COM.ERB` の全COM口上
- 原作正本：`tools/output/{名前}.txt`
- 抽出：`PRINTFORM[LW]` の「」内本文
- 判定：マクロ名だけを正規化し、16文字以上の本文が異なるCHARのCOM間で完全一致するものを抽出
- 目的：定型句ではなく、別CHARの生成文がそのまま流用された可能性のある高精度候補を洗い出す

この監査は「完全一致候補」の抽出であり、同じ行為なら似た反応になる自然な一致まで含む。最終判定は、各キャラの原作正本・設定・COM舞台を読んで行う。今回、ソース本文は変更していない。
