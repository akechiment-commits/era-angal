### 重複・近似重複チェック（COM301拡張時は必須）
完全一致だけでなく「言い換えただけの近似重複」も検出する。COM301を拡張する際、
追加5行を既存5行から言い換えて作ると near-dup になりやすい（過去に多発）。
```python
import re, glob
from collections import Counter
def lcs(a,b):
    a=a.replace('%CALLNAME:PLAYER%先輩','').replace('%CALLNAME:PLAYER%','')
    b=b.replace('%CALLNAME:PLAYER%先輩','').replace('%CALLNAME:PLAYER%','')
    m=[[0]*(len(b)+1) for _ in range(len(a)+1)];best=0
    for i in range(1,len(a)+1):
        for j in range(1,len(b)+1):
            if a[i-1]==b[j-1]:m[i][j]=m[i-1][j-1]+1;best=max(best,m[i][j])
    return best
for p in sorted(glob.glob('ERB/CHAR/*_COM.ERB')):
    t=open(p,'rb').read().decode('cp932')
    lines=re.findall(r'(?m)^\s*PRINTFORM[LW]\s+「(.+?)」\s*$', t)
    full=[(k,v) for k,v in Counter(lines).items() if v>=2 and len(k)>=8]   # 完全重複
    # COM301内 near-dup（共通18字以上・呼称マクロ除外）も別途チェック推奨
    if full: print(p.split('/')[-1], '完全重複', full[:3])
```
- 検証ゲート：完全重複0／COM301内 near-dup(LCS18字以上)0／空0／IF==ENDIF。
- PARTNER_DIALOG拡張時の注意：CASE1/2に既存CASE0と同一行を入れない（過去に63/66/71で再発）。
- 文字列照合より位置ベース置換が安全（渡し分はハーフ角 ? ! が混在し文字列一致が外れる）。
