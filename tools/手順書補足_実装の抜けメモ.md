## 3. メモ：判定スクリプト（空き検出）

```python
import re, glob, os
for p in sorted(glob.glob('ERB/CHAR/CHAR_*.ERB')):
    if 'TEMPLATE' in p: continue
    t = open(p,'rb').read().decode('cp932','replace')
    emp = len(re.findall(r'PRINTFORM[LW]\s+「」', t))
    if emp: print(os.path.basename(p), '空', emp)
```
※@HOURAI が COM ディスパッチ途中に入るキャラでは、空き集計時に
　セクション帰属を取り違えやすい。空きの所在は SELECTCOM 番号で確認すること。
