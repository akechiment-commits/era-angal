# 基本立ち絵（制服・通常表情）

キャラID 1〜71について、`talk_character/<ID>/base/default` から制服姿の通常表情を1枚ずつ選んだもの。

- `character_001.png`〜`character_071.png` の71枚
- `base/default` の高解像度立ち絵だけを対象
- キャラごとの基本ポーズは、`character/whole_body` の立ち絵との画像照合で選定
- 元画像は `server_research/artifacts/usable_assets/talk_character` に残している
- 選択元と照合結果は `selection.csv` に記録
