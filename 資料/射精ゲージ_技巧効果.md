# 射精ゲージと技巧（ABL:2）の効き方　調査資料

対象: `ERB/COMF/CALC_EJAC.ERB`（@CALC_EJAC / @CALC_EJAC_P）

## 基本

- 各性行為コマンドは毎回 `BASE:PLAYER:2 += CALC_EJAC(SELECTCOM, PLAYER)` で射精ゲージを加算する。
- **射精ゲージ満タン = `MAXBASE:2 = 10000`**。ここに達すると射精する。
- よって CALC_EJAC の戻り値 **B = 1回あたりのゲージ増分**。`10000 / B ≒ 射精までの回数`。
- 技巧は `LOCAL:97 = MAX(5, ABL:2)`（**下限5**。技巧5未満は5扱い）。
- 下表のBは**技巧以外を中立**にした値。実際は従順・欲望・潤滑・C感覚・相性・名器度・処女が乗算で上乗せされる。

## 仕組みのポイント

1. **技巧0〜5は横ばい**（下限5）。
2. 各コマンドの技巧チェーンは `B = 基底 + LOCAL:97 * 係数`。技巧12で係数が上がる段差がある（例 正常位 ×100→×150）。
3. **超高技巧ボーナス**（@CALC_EJAC / @CALC_EJAC_P 末尾、`ARG:1==PLAYER`時）:
   - `超過 = ABL:2 - 12`、`倍率% = 100 + 超過*3 + 超過^2*4/10` をBに乗算。
   - 技巧が高いほど加速度的に増え、超高技巧の女性は男を「死ぬほど」射精させる。
   - 倍率: 技巧20→×1.49 / 30→×2.83 / 50→×7.91 / 100→×34.61
   - 調整は係数 `*3`（線形）と `*4/10`（二次）、開始点 `12` で行う。
4. 上記とは別に「下限5」「従順/奉仕の起点5」の調整あり（`MAX(5, ...)`）。

## 高奉仕精神ボーナス（技巧と同方式・別枠で乗算）

技巧と同様、奉仕精神(ABL:6)が高い女性ほど男を多く射精させる加速ボーナスを追加。
@CALC_EJAC / @CALC_EJAC_P 末尾、`ARG:1==PLAYER` 時に適用。技巧ボーナスとは独立に乗算される
（両方高ければ両方乗る）。

- 開始閾値: **奉仕精神16**（16以下は従来通り。16=高奉仕の完成ラインで、それ以上がご褒美）
- `超過 = ABL:6 - 16`、`倍率% = 100 + 超過*3 + 超過^2*4/10`
- 倍率: 奉仕24→×1.49 / 34→×2.83 / 54→×7.91（技巧と同じカーブ形）
- 調整は係数 `*3` / `*4/10`、開始点 `16` で行う。

※技巧ボーナスの開始閾値は **12のまま据え置き**（12が育て終えたライン、それ以上を目指す
やりこみ勢へのご褒美という位置づけ）。
