# 助手調教時レズ経験・調教コマンド経験値監査および修正報告書

## 1. 概要
ユーザーからの指摘「助手調教時のキスでレズ経験が入らない」「助手調教時は全コマンドでお互いにレズ経験が入るのが正しいはず」に基づき、全182個の調教コマンド（ERB/COMF/COMF*.ERB）を網羅的に監査・改修しました。

改修対象は合計 **75ファイル** に及びます。

---

## 2. 最重要バグ：「助手調教時のキスでレズ経験が入らない」原因と修正

### ■ COMF6.ERB（キス）で何が起きていたか
キスコマンドのレズ経験加算判定は以下のようになっていました。

#### 【修正前】
`rb
STAIN:0 |= STAIN:MASTER:0
STAIN:MASTER:0 |= STAIN:0

IF TALENT:122 == 0 && TALENT:MASTER:122 == 0
    PRINTS EXPNAME:40
    PRINTL +3
    EXP:40 += 3
    EXP:PLAYER:40 += 3
`

- **原因**:
  - ASSIPLAY == 1（助手調教）のとき、調教を行っているのは助手（PLAYER = ASSI）です。
  - しかしコード上では TALENT:MASTER:122 == 0（**主人が男ではないか**）を判定していました。
  - そのため、**「主人が男」のデータでは、助手と奴隷が女性同士であってもレズ判定が絶対に成立せず、レズ経験が1ポイントも入らない** 状態になっていました。
  - さらに、口の汚れ（STAIN）や技巧チェック（ABL:MASTER:2）、実行可否判定（COM_ORDER_6）もすべて主人の数値を参照しており、助手の能力や汚れが反映されていませんでした。

#### 【修正後】
`rb
STAIN:0 |= STAIN:PLAYER:0
STAIN:PLAYER:0 |= STAIN:0

IF TALENT:122 == 0 && TALENT:PLAYER:122 == 0
    PRINTS EXPNAME:40
    PRINTL +3
    EXP:40 += 3
    EXP:PLAYER:40 += 3
`
- MASTER 参照となっていた箇所（TALENT、STAIN、ABL、COM_ORDER）をすべて PLAYER に是正しました。
- これにより、助手が調教しているときは助手と対象の能力・汚れ・素質が正しく判定され、お互いに EXP:40 が加算されます。

## 4. 追加修正：3人参加コマンド（複数奉仕系）における「奴隷×助手」判定の追記

### 概要
前回の全75ファイルの一斉修正は**「助手単独調教時（ASSIPLAY == 1）」**における TALENT:PLAYER:122 の反映でした。
しかし、マスター調教中（ASSIPLAY == 0）に助手が参加する3人奉仕コマンド（ダブル素股・ダブルフェラ等）において、**「奴隷と助手同士のレズ・BL判定」が完全に脱落**していることが判明しました。

### 対象ファイルと不具合詳細
1. **ERB/COMF/COMF62.ERB（ダブル素股）**
   - 奴隷と助手が直接肌を重ね合い、汚れも相互移動（STAIN:3 |= STAIN:ASSI:3）している。
   - にもかかわらず、「マスター×奴隷」「マスター×助手」の判定しか存在せず、マスターがオトコ（TALENT:MASTER:122 == 1）の場合にレズ経験が双方0になっていた。
   - **対応**: IF TALENT:122 == 0 && TALENT:ASSI:122 == 0（およびBL判定）を追加し、奴隷と助手にそれぞれ EXP:40 += 7（または EXP:41 += 7）を加算するように修正。

2. **ERB/COMF/COMF68.ERB（ダブルフェラ）**
   - ダブル素股と同様に、奴隷と助手が同時に奉仕し、レズっ気がある場合は唇同士が触れ合う処理もある。
   - しかし「マスター×奴隷」「マスター×助手」しか判定がなく、「奴隷×助手」が欠落していた。
   - **対応**: ダブル素股と同様に「奴隷×助手」のレズ・BL判定を追加。
