## Phase I: イベントボード周回システム ✅ 完了

### イベントデータ仕様

- 月ごとに6イベント × 12ヶ月 = 72イベント
- イベントタイプ: 収拾 / バトル / 宝探し / すごろく

### ゲームフロー

```
月初め選択 → イベント選択 → エリア進行 or ミッション挑戦
  → ミッション発生時: [1]気力を使う [2]エリアに戻る [3]デッキ編成 [0]破棄
  → ミッション成功 → PT獲得・ミッションLv上昇
```

### フラグ仕様

| FLAG:15010〜15015 | イベント別エリア番号 |

### ミッションレベルシステム

- ミッションLvはイベント別×種別別で独立（6イベント×3種=18スロット）
- 初期値Lv1、ミッション達成ごとに+1
- 破棄するとそのミッションLvが-1（最低1）
- 月が変わるとすべてLv1にリセット
- 計算式: `A = FLAG:68 * 3 + 77 + FLAG:15053`（FLAG:15053=1/2/3）

**PT報酬（Lvに応じて増加）:**
```
通常: 2 + 2 * Lv（Lv1=4, Lv2=6, Lv3=8...）
特大: 5 + 10 * Lv（Lv1=15, Lv2=25...）
緊急: 8 + 24 * Lv（Lv1=32, Lv2=56...）
```

### エリア番号システム

- エリアはイベント別で独立（FLAG:15010〜15015）
- 初期値エリア1、進捗100%達成でエリア番号+1
- 踏破時「エリアNに進行！」と表示
- 月が変わるとすべてエリア1にリセット

### 発揮値計算（デッキ依存）

`@EVENT_BOARD_CALC_HAKKIICHI` でデッキ5枚のキャラ能力を集計：

| イベントタイプ | 計算式 |

```erb
    FLAG:15053 = 0   ;ミッション種別
    FLAG:15054 = 0   ;すごろく周回数
    FLAG:15055 = 0   ;エリア進捗
```
