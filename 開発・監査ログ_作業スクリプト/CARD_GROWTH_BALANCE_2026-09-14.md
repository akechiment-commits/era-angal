# カード補正と育成補正のバランス調査（2026-09-14）

全1884カードと71キャラの定義を読み、通常ガチャのレア度・キャラ抽選・カード重み・重複減衰・12枚目ボーナスを含む期待値を計算した。イベント発揮値のカード2倍だけを無効化する修正を適用済み。ガチャ、共通カード再計算、校内定期戦、CSV、セーブは変更していない。

## 先に結論

イベント発揮値の2倍を無効化すれば、今回確認した「第4補正タイプのキャラだけカードで伸びる」差はほぼ消える。ただし、カード補正と育成補正の比率は別問題として残る。2倍を外した後でも、次の3つは残る。

- カードの種類数がキャラごとに13～39枚で違う。通常ゴールドガチャ710回（各キャラ平均10枚）のカード由来発揮値は、同じ条件でも1077～1453の範囲になる。最大と最小で約1.35倍。
- イベントごとにピックアップと固定報酬のカードが違う。特定イベントを周回すると、そのイベントの対象キャラがさらに伸びる。
- カードの重複ボーナスは12枚目で段差がある。カードは技能ABLのような100上限がなく、重複を続ける限り伸びる。

したがって、2倍無効化は「タイプ間の公平性」に対する第一修正としては十分だが、「全キャラのカード成長を均等にする修正」ではない。

## 2倍をイベントだけで無効化したとき

共通再計算の `CFLAG:306 *= 2` は残し、イベント側で `CFLAG:Z:306 / 2` として合計する修正を適用した。`CFLAG:306` はカード一覧と校内定期戦でも使われるため、共通処理から行を削除すると影響範囲が広がる。

| 場面 | イベントだけ無効化した場合 |
|---|---|
| ガチャ排出・カード所持数・重複計算 | 変化なし |
| カードコレクション画面 | 表示変化なし |
| 校内定期戦のスコア | 変化なし |
| 校内定期戦の自動編成 | 変化なし |
| 部活・試験・体育祭・文化祭・日常コマンド | カードを直接参照しないため変化なし |
| イベント発揮値 | 第4補正タイプだけに乗っていた2倍分を除去 |
| イベントミッションの目標値・報酬・PT | 変化なし |
| イベントで必要な攻撃回数・気力消費 | 第4補正タイプのカードが多いデッキほど増える |
| 発揮値内訳表示 | 実計算と同じく `CFLAG:306 / 2` にする必要がある |

例えば基本値60のSRを新品で1枚持つ場合、イベントへの加算は現在、表現330・運動360・学力360・第4補正450。イベント側だけ戻すと4タイプとも300になる。ミッション報酬の量を減らす処理ではなく、同じミッションを何回の攻撃で終えるかだけが変わる。

## 発揮値全体で見たカードと育成の比率

先に示した「SR1枚＝得意ABL+20」は、収拾・バトルのABL部分だけを単位換算した説明だった。発揮値全体には、全4能力、親密度、イベント種別、属性ボーナス、5人編成倍率、恋慕ボーナス、人形ボーナスが入るため、それだけでカードの強さを判断してはいけない。

実際の計算は、1キャラごとに次の順で行われる。

1. 親密度（通常は1/10、すごろくは追加1/10、親愛度は追加1/5）を加算。
2. イベントごとの4能力重みを加算。収拾・バトルは得意15・他5、宝探しは学力12・知識10・他3、すごろくは全5、親愛度は表現10・他3。
3. カード4補正を合計し、イベントでは各5倍。2倍無効化後は第4補正も元の値で合計する。
4. ABLまたは親密度の平均が条件を満たした場合、合計全体に1.2倍。
5. 5人編成なら合計全体に1.1倍。主人公の恋慕ボーナスはさらに合計全体へ加算する。

カードは属性ボーナスの判定値Cには入らない。カードだけで1.2倍条件を発生させることはできず、育成したABLや親密度が条件を満たした後に、カード分も含めた合計へ1.2倍が掛かる。

平均的な初期能力のキャラ、親密度500、SR新品1枚を5人全員に持たせ、恋慕・人形ボーナスなしで比較した例。親密度500はすごろく・親愛度の属性ボーナス条件を確認するための固定値で、全プレイの平均を意味しない。

| イベント | 育成＋親密度 | カード | カード比率（最終合計） |
|---|---:|---:|---:|
| 収拾 | 433 | 300 | 41% |
| バトル | 425 | 300 | 41% |
| 宝探し | 733 | 300 | 29% |
| すごろく | 427 | 300 | 41% |
| 親愛度 | 385 | 300 | 44% |

5人編成倍率や属性倍率はカードと育成の両方に掛かるため、比率自体はおおむねこの範囲に留まる。親密度を0にすれば、親愛度イベントではカード比率がさらに高く見える。逆に親密度や恋慕が高ければカード比率は下がる。

中盤の目安として技能ABLを各+50、親密度500、ゴールドガチャ355回相当（平均5枚/キャラ、カード加算平均753）で同じ計算をすると、カード比率は収拾・バトル約31%、宝探し約33%、すごろく・親愛度約39%。この値はABLだけを分母にした以前の比較より低く、発揮値全体を分母にした値である。

したがって、イベント係数5は「カードが育成の数倍強い」とまでは言えない。初期の親密度が低い状態や、宝探し以外の能力が未育成な状態ではカードが目立つが、中盤以降は育成・親密度・属性倍率も同じ合計へ作用する。実機で問題になるかは、カード枚数ではなく、同じミッションを終える攻撃回数で判定する。

### 判定

- 初期はカード5枚/人で、Lv5特大の必要攻撃回数が17～27回から5～7回まで減る。カードの効果はかなり大きい。
- 中盤ではカード0枚/人でも4～5回、5枚/人で3回、10枚/人で2～3回。カードは育成を置き換えるというより、攻撃回数を1～2回減らす位置に収まる。
- 終盤ではカード0枚/人でも2～3回で、カードを増やしても2回前後。ABL育成が進むとカードの相対効果は下がる。

これは平均能力と期待カード値による計算であり、実際のデッキ編成・キャラ別カード枚数・親密度・恋慕ボーナスで前後する。実機で確認する場合は、同じミッションLvで「カード0／5枚／10枚」と「初期／中盤／終盤」を比較すれば、係数5を下げる必要があるか判断できる。

共通処理から2倍を削除すると、校内定期戦でも第4補正タイプの優位が消える。SR基本値60の新品1枚なら、カード部分は第4補正タイプで180から120へ、表現型なら132から120へ下がる。5人デッキではカード構成により1戦あたり数十～数百点の差になるため、イベント限定の無効化が安全。

## カード1枚と技能ABLの単位比較

イベント側で2倍を無効化した場合、カードの合計値はレア度の基本値に戻り、イベントカード係数5を掛ける。

| レア度 | 基本値 | イベントへの加算（新品1枚） |
|---|---:|---:|
| N | 8 | 40 |
| R | 20 | 100 |
| HR | 36 | 180 |
| SR | 60 | 300 |
| UR | 100 | 500 |
| MR | 160 | 800 |

収拾・バトルでは、得意ABLが1上がると15点、他のABLが1上がると5点。よって新品SR1枚（300点）は、得意ABLを20上げるのと同じ、または非得意ABLを60上げるのと同じになる。

宝探しでは学力12、知識10、他3。すごろくでは全ABL5。親愛度では表現10、他3。したがって同じカードでも、イベントタイプによって「何ABL分に見えるか」は変わる。これはイベントごとに育成方針を変えるための仕様であり、カードタイプの偏りとは別に考える必要がある。

## 12枚目の段差

カード1種類の所持数Kは、通常は `基本値 + (K-1)×基本値/レート`。Kが12になると基本値の3倍を追加する。イベント2倍を無効化した場合のイベント加算で、11枚目と12枚目は次のようになる。

| レア度 | 11枚目までの値 | 12枚目到達後 | イベント加算の変化 |
|---|---:|---:|---:|
| N | 12 | 36 | 60 → 180 |
| R | 40 | 102 | 200 → 510 |
| HR | 72 | 183 | 360 → 915 |
| SR | 180 | 372 | 900 → 1860 |
| UR | 350 | 675 | 1750 → 3375 |
| MR | 960 | 1520 | 4800 → 7600 |

この段差はタイプ公平性には影響しないが、カード成長を急に感じさせる。特にN～HRは12枚目で2.5～3倍になる。一度に12枚集める機会が少ないなら収集目標として機能するが、低レアカードが偏って出るキャラでは早期に発生しうる。

## 調整の順番

1. イベントだけ第4補正の2倍を無効化する。これでタイプ固定による約4割の差を消す。
2. その状態で、実機のイベントミッションを「初期・技能50前後・技能100前後」の3段階で確認する。見る値は、通常・特大・緊急ミッションを終える攻撃回数と、1イベントに使う気力。
3. カードが強すぎる場合だけ、イベント係数5を4へ下げる。係数4ならカード値は現在の80%、係数3なら60%。ガチャの価値と校内定期戦は維持できる。
4. 12枚目の急増が問題なら、カード全体を弱くする前に、追加ボーナスを基本値の3倍から1～2倍へ下げるか、11枚目までに分散する。
5. キャラ間の残る35%程度の差まで揃える必要がある場合は、カード総数ではなく「レア度別の期待カード値」を基準に補正する。イベント係数だけを下げても、この差は消えない。

## 今の段階での推奨

まずはイベント側だけ2倍を無効化し、係数5・重複曲線・ガチャ率は維持する。理由は、2倍がタイプ差の主因である一方、係数5や12枚目ボーナスはカードを集める動機そのものだから。実機で攻撃回数が過度に短縮される場合に、係数5を4へ下げる順番が調整しやすい。
