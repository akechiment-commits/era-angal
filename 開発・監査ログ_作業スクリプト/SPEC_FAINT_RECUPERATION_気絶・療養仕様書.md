# 気絶・体力マイナス・衰弱療養システム 仕様書

## 1. 基本設計思想と概要
本システムは、ウフフ（調教）中の過剰な体力消耗による**「気絶（意識喪失）」**と、気絶後も行われた行為に伴う**「負の体力（マイナス体力）蓄積」**、およびそれによって生じる長期休養**「衰弱療養（お休み）」**を統括する基幹システムである。

- **リスク＆リターン**: 相手が気絶しても調教を強行できるが、体力がマイナスに深く落ち込むほど、調教終了後の衰弱療養期間（一切の調教・行事に参加できない期間）が長期化する。
- **マイナス体力の絶対保持**: 気絶によって減少した体力（例: -6462）は、**調教終了時・ショップ画面・リスト表示等で絶対に0にクランプ・リセットしてはならない**。
- **自然回復による段階的復帰**: ターン経過（休憩等）で体力回復量が蓄積され、体力が正の値（> 0）に戻って初めて衰弱療養から復帰する。

## 2. 調教中（ウフフパート）の気絶仕様

### 2.1 発生条件とフラグ管理
- **発生契機**: ウフフ中（TFLAG:44）に BASE:TARGET:0 <= 0 となった瞬間。
- **管理フラグ**:
  - TFLAG:898（初回気絶発生フラグ）:
    - 0の状態で体力 $\le 0$ に達したターンの終了時に1へ遷移。
    - 気絶アナウンスを出力（「極度の疲労により、意識を失い気絶してしまいました……！」）。
    - 主導権の強制剥奪（TFLAG:34 = 0, TFLAG:45 = 0）。
    - 親密の低下、異常経験の加算（素質条件等に応じる）。
  - TFLAG:899（気絶継続中フラグ）:
    - SHOW_USERCOM の開始時に BASE:TARGET:0 <= 0 を判定し、常時1にセット。
    - 調教コマンドの実行可否・口上制御・パラメータ計算の判定フラグとして機能。

### 2.2 コマンド実行制御
- **ホワイトリスト制（COMABLE.ERB / @COM_ABLE_FAINT_CHECK）**:
  - 意識のない相手に対して実行可能なコマンドのみ許可（愛撫、胸愛撫、キス、クンニ、道具装着、正常位・後背位等の特定性交、撮影等）。
  - 会話、奉仕、騎乗位、対面座位、相手の自発的アクションを伴うコマンドは完全不可。
- **実行値判定のバイパス**:
  - 気絶中コマンドは相手の合意や能動的拒絶が存在しないため、**実行値の成否に関わらず無条件で実行可能**（実行値の計算・表示自体は行われる）。

### 2.3 パラメータ・口上・経験の制御
- **好感度・好意・恭順の上昇停止**:
  - 気絶中は相手の意識がないため、ターン経過や快楽による好感度加算・好意/恭順ジュエル獲得は一切行われない。
- **苦痛・恐怖と体力消費の加速**:
  - 肉体的な苦痛・恐怖は意識下でも身体に刻まれるため正常に加算される。
  - 苦痛に伴う体力消費増大ペナルティもそのまま適用される。
- **口上および地の文の完全抑制・修正**:
  - 意識がないため、処女喪失時や中出し時、絶頂時等のキャラ口上は再生を完全ブロック。
  - 射精地の文において、相手側がふたなり射精したかのような誤表記を防止し、プレイヤー側の射精文のみを正しく描写。
- **快楽依存・既成事実の獲得遮断**:
  - 気絶中の行為によって既成事実や快楽依存が付与されることを防ぎ、それに連動した能力（欲望・親密等）の意図せぬ上昇を遮断。

### 2.4 体力マイナスの蓄積
- コマンドごとの体力消費量（LOSEBASE:0）および苦痛等による追加消費は、体力が0以下になっても**下限なし（リミットなし）でマイナス方向へ減算され続ける**。

### 2.5 気絶中の専用地の文と能動メッセージ抑制
- **挿入Ｇスポ攻め・挿入子宮口攻めの専用化**:
  - SELECTCOM == 255 || SELECTCOM == 364（挿入Ｇスポ攻め／着衣）および SELECTCOM == 256（挿入子宮口攻め）に対し、正常位と共通にせず各部位・体位に特化した専用の気絶時地の文（RAND:2 分岐あり）を実装。
  - 脱力した身体への刺激、無意識の痙攣や吐息など、意識喪失状態に即した描写を行う。
- **能動的リアクションの完全抑制**:
  - 射精時等に発生していた「足を絡め腰を押し付けてきた」「首に手を回して抱きついてきた」等の能動的メッセージに対し、&& TFLAG:899 == 0 && BASE:TARGET:0 > 0 を追加し、気絶中は発生しないよう完全に抑制。
- **事後テキスト（@TEXT）での悲鳴・叫び・許しを乞うメッセージの遮断・差し替え**:
  - スパンキング（COM40）、鞭（COM41）、針（COM42）等の苦痛系コマンド実行時に @TEXT（EVENT_TEXT_イベントテキスト.ERB）から発生していた「叫んだ」「許しを乞うた」等の能動的リアクションを完全遮断。
  - 気絶中は、意識のない身体が衝撃で力なく跳ねる、苦しげな吐息が漏れる等の無意識な痛撃反応メッセージに差し替え。道具使用・愛撫系コマンドに対しても同様に無意識反応への差し替えを適用。
- **挿入Ｇスポ攻め・挿入子宮口攻めの専用化**:
  - SELECTCOM == 255 || SELECTCOM == 364（挿入Ｇスポ攻め／着衣）および SELECTCOM == 256（挿入子宮口攻め）に対し、正常位と共通にせず各部位・体位に特化した専用の気絶時地の文（RAND:2 分岐あり）を実装。
  - 脱力した身体への刺激、無意識の痙攣や吐息など、意識喪失状態に即した描写を行う。
- **能動的リアクションの完全抑制**:
  - 射精時等に発生していた「足を絡め腰を押し付けてきた」「首に手を回して抱きついてきた」等の能動的メッセージに対し、&& TFLAG:899 == 0 && BASE:TARGET:0 > 0 を追加し、気絶中は発生しないよう完全に抑制。

### 2.6 体力大幅マイナス時の最大値減少ペナルティ
- **発動条件**: ウフフ調教中に体力が -1000 以下に達している状態。
- **ペナルティ内容**:
  - コマンド実行（@EVENTCOMEND）ごとに、過度な負荷の代償として**最大体力（MAXBASE:0）および最大気力（MAXBASE:1）が少しずつ減少**。
  - 減少量: マイナス深度に応じた段階的減算（体力: 5〜25、気力: 5〜20）。
  - 下限リミット: 最大体力・最大気力ともに最低保証値 500 未満には減少しない安全ガードを実装。
  - 発生時に赤字で過大負荷のアラートと減少量を明示。

## 3. 調教終了時の仕様

### 3.1 調教終了処理（AFTERTRA_調教後処理.ERB）
- **マイナス体力の維持（0クランプ絶対禁止）**:
  - @LIFE_LIMIT_MAXBASE は上限（MAXBASE）のみを調整し、下限はいかなる値（例: -6462）でもそのまま保持する。
  - SIF BASE:TARGET:0 < 0; BASE:TARGET:0 = 0 のような代入・クランプは**絶対に禁止**。
- **見送り口上の制御**:
  - BASE:TARGET:0 <= 0（気絶・衰弱中）の場合は、通常の見送り口上をスキップし、保健室やベッドで休ませる描写に差し替え。
- **事後成長（@EVENT_GROWTH）の完全停止**:
  - 調教中に気絶した場合（TFLAG:898）、または気絶・衰弱中（BASE:TARGET:0 <= 0）に調教終了した場合、調教後の体力・気力最大値自然成長（@EVENT_GROWTH）を完全スキップ。
  - 極度の疲労や気絶状態で「体力が付きました」と最大値が成長してしまう矛盾を防止。
- **事後処理のスキップ**:
  - 労役（EARN_MONEY_TM）や自慰チェック（SELF_CHECK）は BASE:TARGET:0 > 0 の場合のみ呼び出し、衰弱キャラは除外。

## 4. ショップ画面・日常パートの仕様

### 4.1 衰弱療養中（お休み）の判定基準
- **判定式**: BASE:キャラクター:0 <= 0

### 4.2 ショップメニューの制限（SHOP_ショップ.ERB）
- **ステータス表示**:
  - パートナー情報欄の体力表示に 【衰弱（お休み）】 を赤字表示。
  - 負の数値をそのまま表示（例: (-6462/ 807)）。
  - バー描画用には一時変数を用い、元の BASE:0 を汚染・変質させない。
- **[100] 調教コマンド**:
  - パートナーが療養中の場合、メニュー表記を [100] - (パートナー療養中) に変更。
  - 選択時は「（体力を消耗して衰弱療養（お休み）のため、今は一緒に過ごせません）」と表示し調教開始を完全ブロック。
- **[102] アルバイト**:
  - パートナーが療養中の場合、同行不可としてブロック。
- **[105] 待機中動作指示 (SHOP_COM_ACT_ショップコマンド.ERB)**:
  - 衰弱療養中キャラ (`BASE:COUNT:0 <= 0`) は、待機行動として **`[0] 何もしない`** または **`[2] リフレッシュ`** のみ選択可能 (`@SHOP_ACT_ABLE`)。
  - 勉強・運動・掃除・性奉仕などの通常行動は選択肢から除外・入力ブロック。
  - キャラ一覧表示 (`@ACTION_LIST`) において、療養中キャラには赤字で `【療養中】` バッジを表示。
  - ショップ開始時および待機指示画面入場時 (`@ALL_ACT_ABLE`)、療養中キャラが不適格な行動に設定されていた場合は自動的に `[2] リフレッシュ` に自動是正。
  - 全員一括指示 (`[300]`) で他の行動（勉強など）が指定された場合も、療養中キャラはスキップされ設定が保護される。
- **[106] 休憩**:
  - パートナーが衰弱療養中の場合、通常の意識ある休憩口上 (`CHAR_REST_{NO:TARGET}`) の呼び出しを完全に遮断。
  - 代わりに「（%CALLNAME:TARGET%は衰弱療養中のため、保健室のベッドで静かに眠っている……）」を表示し、静かに時間経過させる。
- **[110] パートナー変更 / [111] 助手変更**:
  - キャラ一覧表示（@LIFE_LIST）で療養中キャラに [療養] バッジを赤字付与（3列表示でも赤字識別）。
  - リスト描画時に BASE:COUNT:0 を0クランプする処理を排除（バー描画は一時変数を使用）。
  - 療養中キャラを選択した場合は警告メッセージを表示し、選択を拒絶（再入力ループ）。

### 4.3 日常イベント・学内行事からの完全除外
- **朝イベント（EVENT_MORNING）**:
  - 療養中キャラの朝イベントをスキップ（「衰弱療養（お休み）のため、朝のイベントは発生しません」）。
- **校内遭遇・場所イベント（LOCATION_EVENT）**:
  - 遭遇しても療養中のためパートナー勧誘を不可とする。
- **昼食・食事イベント（LUNCH_EAT, LUNCH_SELF_EAT）**:
  - 療養中キャラとの同席・自炊を不可とする。
- **体育祭・文化祭（SCHOOL_EVENT） / 定期試験（STAGE）**:
  - 行事への参加不可、または保健室で療養中である旨の個別メッセージを表示。
- **部活動（CLUB_ACTIVITY）**:
  - 療養中キャラの部活動参加を除外。

## 5. 自然回復と療養復帰のメカニズム

### 5.1 ターンエンドの回復計算とリフレッシュ（SYSTEM_基本システム処理.ERB / SHOP_COM_ACT.ERB）
- ターン終了（休憩 [106]、調教終了、日付変更等）時、各キャラクターに所定の体力回復量 A が加算:
  $$\text{BASE:COUNT:0} \leftarrow \text{BASE:COUNT:0} + A$$
- **基礎回復量**: 昼（MAXBASE/4）、夜（MAXBASE/2）、休憩ボーナス（+100）等。
- **待機行動「リフレッシュ」の効果**:
  - 体力回復量 $A$ が **2倍** (`A *= 2`)。
  - 耐力回復量 $B$ が **2倍** (`B *= 2`)。
  - 生活費 $C$ が **3倍** (`C *= 3`) に増加（治療・静養費）。
  - ※衰弱療養中 (`BASE:COUNT:0 <= 0`) の場合は、好感度の上昇 (`CFLAG:COUNT:2 += LOCAL`) をブロック。
- **療養中の回復可視化（ログ通知）**:
  - ターンエンド時、療養中キャラ (`LOCAL:97 <= 0 && BASE:COUNT:0 <= 0`) につき水色文字で進行状況を毎ターン表示:
    `%CALLNAME:COUNT%は衰弱療養中……（体力+{A}、現在：{BASE:COUNT:0}/{MAXBASE:COUNT:0}）`
  - これによりリフレッシュの効果や復帰までの残り数値が一目で確認可能。

### 5.2 復帰判定
- 増加前体力（LOCAL:97）が $\le 0$ であり、加算後の新体力（BASE:COUNT:0）が **$> 0$（正の値）** に到達した時のみ、衰弱療養復帰と判定。
- 復帰時、画面に緑色で通知表示:
  ```
  %CALLNAME:COUNT%の体力が回復し、療養（お休み）から復帰しました！（体力：{BASE:COUNT:0}）
  ```
- 体力が $> 0$ になるまでは何ターンでも衰弱療養（お休み）が継続する。
